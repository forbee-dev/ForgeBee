# content-creator — Reference Material

Working library for `forgebee/agents/content-creator.md`. The persona holds workflow, gates, and Never rules.

---

## Core Content Frameworks

| Framework | Steps |
|-----------|-------|
| Hook-Story-Offer (Brunson) | Hook (from hook library) → Story (connection) → Offer (clear CTA) |
| Hook-Retain-Reward (Hormozi) | Hook (bold claim, stat, pain question) → Retain (value that holds attention) → Reward (payoff) |
| PAIPS (Welsh) | Problem → Amplify → Intrigue (hint at solution) → Proof → Solution |
| PAS | Problem (name the pain) → Agitate → Solution |

## Platform Templates

### LinkedIn Post
```
[Hook line — stops the scroll]

[2-3 sentences of context/story]

Here's what I learned:

→ [Insight 1 with specific detail]
→ [Insight 2 with data point]
→ [Insight 3 with actionable takeaway]

[Closing thought that reframes the hook]

[Specific engagement question]

---
[Max 3-5 hashtags]
```

Rules: first 2 lines earn the "see more" click. Use line breaks. Stories beat tips; data beats opinions. 3-5 posts/week.

### X/Twitter Thread
```
1: [Hook — surprising stat or bold claim]. Let me explain ↓
2-5: [One point each — context, example, data, story]
6: The takeaway: [one sentence]. → Follow @handle → Repost the first post
7: [Bonus insight or resource link]
```

Rules: the hook post stands alone. Each post is self-contained but builds on the last. Number the posts. 5-15 posts.

### Instagram Caption
```
[Hook — first line visible without expanding]

[Story or context, 2-3 short paragraphs]

[Key takeaway]

[CTA — "Save this for later" / "Share with someone who needs this"]
.
.
[5-15 relevant hashtags]
```

### Instagram Carousel
```
Slide 1: [Hook headline — large, bold]
Slide 2: [Problem]
Slides 3-5: [One point per slide with visual]
Slide 6: [Key insight or summary]
Slide 7: [CTA — save / follow / share + profile tag]
```

### TikTok/Reels Script
```
[0-2s]   HOOK: [bold statement or question — on-screen text + spoken]
[2-5s]   CONTEXT: [why this matters]
[5-20s]  VALUE: [tips, steps, or story]
[20-25s] PAYOFF: [key insight or transformation]
[25-30s] CTA: [follow / save / comment]
On-screen text · Music/sound · Visual notes
```

### YouTube Script
```
[0:00-0:10] HOOK: promise of value
[0:10-0:30] CONTEXT: establish the problem
[0:30-2:00] SETUP: background, story, or framework
[2:00-8:00] CONTENT: steps, insights, demos
[8:00-9:00] SUMMARY
[9:00-10:00] CTA: subscribe, comment, watch next
```

### Email

## Hook Stacking (video)

Stack hooks on every channel in the first frame:
1. Visual — movement, contrast, the unexpected
2. Audio — trending sound, tone shift, silence break
3. Verbal — spoken hook phrase
4. Text — on-screen text that reinforces the verbal hook

# ForgeBee Setup & Configuration

## Objective

Initialize ForgeBee for a project: CLAUDE.md, TASKS.md, PM system, session directories. Target: a working setup in under 5 minutes.

## Never

- Never overwrite an existing CLAUDE.md. Merge, or confirm with the user first.
- Never skip asking about the project's stack and conventions.
- Never create a directory without checking what already exists.

## First-Time Setup

1. **CLAUDE.md** — from `${CLAUDE_PLUGIN_ROOT}/skills/forgebee-setup/references/claude-md-template.md`. Ask the user for stack, conventions, key components, and common commands. Write to the project root.
2. **TASKS.md** — if absent, create it with empty Active / Waiting On / Done sections.
3. **PM system** — copy templates:
   - `docs/pm/state.yaml` from `${CLAUDE_PLUGIN_ROOT}/templates/docs/pm/state.yaml`
   - `docs/pm/index.md` from `${CLAUDE_PLUGIN_ROOT}/templates/docs/pm/index.md`
   - `docs/pm/decisions.md` from `${CLAUDE_PLUGIN_ROOT}/templates/docs/pm/decisions.md`
   - Create `docs/pm/features/`, `docs/planning/briefs/`, `docs/planning/requirements/`, `docs/planning/stories/`.
4. **Session directories** — `.claude/sessions/`, `.claude/session-cache/context-backups/`, `.claude/learnings/learnings.md`.

Setup ends when these exist.

## Command / Agent / Skill Reference

Do not keep a command list here; it drifts. The inventory lives in:
- **`forgebee/INDEX.md`** — generated by `scripts/build-index.js`, loaded on SessionStart. Never hand-edited.
- **`forgebee-help` skill** — for "what commands are available" or "how do I use ForgeBee". It reads INDEX.md.

## Permission Mode Recommendation

Experienced users can use auto mode for fewer prompts:

```bash
claude --permission-mode auto
```

Claude's safety classifier approves safe operations. ForgeBee's permission-guard Tier-0 blocklist runs before the classifier in every mode, so dangerous commands stay blocked.

**Requirements:** Team/Enterprise plan, Anthropic API, Sonnet 4.6 or Opus 4.6.

Without auto mode, the default mode works; ForgeBee's allowlist covers common safe commands.
